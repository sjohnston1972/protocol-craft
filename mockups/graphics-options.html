Protocol Craft — element art options

Same elements, three visual treatments. Everything here is inline CSS + SVG generated in the page — the exact tech we'd ship. No images, no icon fonts, no emoji, fully offline.

Option A — Typographic chips cleanest · recommended

Name + tier colour + accents only. Milestones get a glowing ring and a corner notch; disasters get a hazard edge and a slow pulse; the HTTPS summit gets an animated gradient ring. No per-element icons.

Option B — Chips + generative glyph most distinctive

Every element seeds its own little symmetric SVG mark (identicon-style, deterministic — same name always makes the same glyph), tinted to its tier. Distinct per element, zero hand-drawn assets.

Option C — Chips + shared layer icons most legible

One hand-picked line-icon per layer/family (switch = L2, router = L3, lock = security/L6, globe = L7…). You learn to read the stack at a glance, but elements within a layer share a mark. ~12 icons total.
